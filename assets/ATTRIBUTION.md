# 🎨 Visual Assets & Diagram Attribution

All diagrams, charts, and visual assets in this repository are either:
1. **Directly rendered via Mermaid.js** inside Markdown files (flowcharts, sequence diagrams, state machines).
2. **Custom-created vector graphics (SVG)** and diagrams generated specifically for this repository, licensed under the repository's MIT License / CC BY-SA 4.0.
3. **Public domain or CC0 reference packet structures** based directly on IETF RFC specifications and IEEE standards.

---

## Standards and RFC Sources

- **Ethernet Frame Layouts:** IEEE 802.3 Standard Specification.
- **IPv4 Protocol & Header:** [RFC 791 (Internet Protocol)](https://datatracker.ietf.org/doc/html/rfc791).
- **IPv6 Specification:** [RFC 8200 (Internet Protocol, Version 6 Specification)](https://datatracker.ietf.org/doc/html/rfc8200).
- **TCP Protocol & State Machine:** [RFC 9293 (Transmission Control Protocol)](https://datatracker.ietf.org/doc/html/rfc9293), RFC 793.
- **UDP Protocol:** [RFC 768 (User Datagram Protocol)](https://datatracker.ietf.org/doc/html/rfc768).
- **DNS Protocol:** [RFC 1034 & RFC 1035 (Domain Names)](https://datatracker.ietf.org/doc/html/rfc1035).
- **DHCP Protocol:** [RFC 2131 (Dynamic Host Configuration Protocol)](https://datatracker.ietf.org/doc/html/rfc2131).
- **HTTP/1.1, HTTP/2, HTTP/3:** RFC 9110, RFC 9112, RFC 9113, RFC 9114.
- **Spanning Tree Protocol:** IEEE 802.1D / IEEE 802.1Q.
